# Data statement

The project used course-provided text and sentiment CSV files documented in the local project report. The working files were local assignment inputs under the UNT NLP project folders. Raw copies are excluded because they are course/distributed data and are not necessary to review the implementation.

To reproduce, obtain the same assignment data from the course source or an authorized equivalent, place the files at the paths expected by the scripts, and update the scripts' input paths. The expected schema is a text field plus a sentiment/label field; the report is the authoritative source for the exact file names and preprocessing assumptions.
