# NLP Language Modeling and Sentiment Classification

**Timeline:** April 2026  
**Category:** Main project

This project implements progressively richer NLP models for language modeling and binary sentiment classification. It covers n-gram modeling with Laplace smoothing, perplexity evaluation, bag-of-words features, and neural sequence models with embeddings, self-attention, Transformer blocks, and LayerNorm.

## Stack

Python, NumPy, PyTorch, CSV, bag-of-words, logistic regression, gradient descent, `nn.Embedding`, positional embeddings, self-attention, Transformer, precision, recall, and F1.

## Repository contents

- `src/assignment2.py` — statistical language modeling and classical sentiment baseline.
- `src/assignment3.py` — neural sequence modeling and attention experiments.
- `reports/` — the project-specific report.
- `data/README.md` — dataset provenance and excluded-data instructions.

## Reproduction

Create a Python environment from `requirements.txt`, place the course CSV inputs at the documented local paths, and run the scripts from `src/`. Raw course data is intentionally excluded from this public repository.
